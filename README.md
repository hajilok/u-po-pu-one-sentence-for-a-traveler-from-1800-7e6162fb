# One Sentence for a Traveler from 1800

Entry for the [make.fun](https://make.fun/r/41fw6r6c) bounty **One Sentence for a Traveler from 1800** (`u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb`).

## What it does

`main.ts` deterministically validates and writes a single sentence (<= 200 UTF-8 characters, strictly pre-1800 vocabulary) explaining the modern internet to a traveler arriving from the year 1800 into `/output/entry.txt`.

## Running

```bash
node main.ts
```
